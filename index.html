Cosine Similarity Formula
similarity(t₁, t₂) = (t₁ · t₂) / (||t₁|| ||t₂||) = cos(θ)

The angle θ between vectors determines similarity: 0° = identical, 90° = independent, 180° = opposite.

Attention Formula
attention = softmax(QK^T / √d_k) × V

Query (Q) represents what we're looking for. Keys (K) represent what's available. Values (V) are the actual content.

Temperature

Control randomness in model outputs. Adjust the slider to see probability distribution changes.

Temperature Control
Temperature: 1.0
Temperature Formula
p_i = exp(x_i / T) / Σ exp(x_j / T)

T → 0: Deterministic (always picks highest probability)
T = 1: Standard sampling
T → ∞: Uniform random (all tokens equally likely)

LoRA

Low-Rank Adaptation for efficient fine-tuning. Adjust rank to see parameter reduction.

Parameter Efficiency
Rank (r): 8
LoRA Formula
W ≈ W₀ + B × A, where B ∈ ℝ^(d×r) and A ∈ ℝ^(r×k)

Instead of updating all parameters in W, we freeze W₀ and learn low-rank matrices B and A.
